Opção 1 — Enviar o arquivo de DRE da contabilidade (recomendado)

Pode subir o mesmo arquivo Excel de sempre, com uma aba por obra (ex: "OBRA 251", "OBRA 265", "DEMAIS OBRAS"...). O sistema identifica sozinho cada obra, cada categoria e os valores de cada mês — não precisa reformatar nada.

Obras que ainda não existem no sistema são cadastradas automaticamente. Categorias que já existem no plano de contas são reconhecidas mesmo com pequenas diferenças de acento/maiúscula; categorias realmente novas são criadas automaticamente. Importar o mesmo mês de novo atualiza os valores (não duplica). As abas "TOTAIS" e "DEPTO TÉCNICO" ainda não são lidas automaticamente — isso está no plano de próximos passos.
